# Preço da Hora - Mobile (Expo)

Aplicativo React Native (Expo) para busca de produtos pelo nome ou GTIN, mostrando resultados apenas das cidades:
- Vitória da Conquista
- Itambé
- Itapetinga

## Como rodar

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Execute o app:
   ```bash
   npx expo start
   ```

## Funcionalidades
- Busca por nome ou GTIN
- Lista de resultados com nome, preço e cidade
- Interface simples, moderna e responsiva

> **Obs:** Para rodar no emulador Android local, o endereço do backend deve ser `http://10.0.2.2:3001`. Para testar no dispositivo físico, ajuste para o IP da sua máquina.
